# fnx Skill Prototypes

This directory contains draft skill prototypes for making `fnx` easier to use with coding agents.

## Included prototypes

- `fnx-guide` — explains what `fnx` can do and maps user goals to the right CLI workflow
- `fnx-existing-app-review` — reviews an existing Azure Functions app and recommends the best `fnx` onboarding flow
- `PROPOSED_SKILLS.md` — proposal for a broader 6-skill direction

## Intent

These files are draft artifacts for discussion and experimentation. They are designed to clarify what an agent-friendly experience for `fnx` could look like before implementing deeper product changes such as `fnx setup`, `fnx chat`, `fnx migrate`, or `fnx audit`.
